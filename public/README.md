# Учебный помощник группы

Приложение для учёбы: расписание пар с числителем/знаменателем, задания и дедлайны, голосовые команды. Сделано для группы психологов вечернего факультета.

## Что это

Мобильное веб-приложение (PWA). Открывается в браузере телефона, добавляется на экран «Домой» и работает как обычное приложение, в том числе без интернета.

## Где что лежит

- `src/lib/config.ts` — **главный файл настроек**. Здесь якорь чётности недель (с какого понедельника считать числитель) и адрес страницы группы на сайте СГУ. Если вуз перевернёт чётность на следующий год — правится одна строка здесь.
- `src/lib/seed.ts` — начальные данные: предметы, преподаватели, расписание, задания. Это то, что видит новый человек, впервые открывший приложение.
- `src/lib/schedule.ts` — логика расписания: какие пары в какой день, чётность, переносы.
- `src/lib/store.ts` — хранение данных (у каждого пользователя на его телефоне, в localStorage).
- `src/lib/voice.ts` — разбор голосовых команд («доклад на ближайшую пару по истории»).

## Личные данные

Приложение ничего не отправляет на сервер. Отметки «сделано», свои пункты, переносы пар — всё хранится только на телефоне каждого пользователя. Кнопка «Резервная копия» внизу главной страницы выгружает всё в JSON-файл.

## Синхронизация с сайтом СГУ

Раз в день GitHub Actions запускает `scripts/sync-sgu.mjs`: читает страницу расписания группы на сайте СГУ и обновляет `src/lib/seed.ts`. Принцип: **только добавлять новое** (новые пары, новых преподавателей). Всё, что человек поменял у себя руками, не перезаписывается — правки пользователя всегда в приоритете.

## Как собрать локально

```
npm install
npm run build
```

Результат — папка `dist/`, её можно разместить на любом статическом хостинге.

## Деплой

При пуше в ветку `main` GitHub Actions сам собирает проект и публикует его на GitHub Pages.
